# 일일 수집·Slack 브리핑 사양

이 문서는 기존 예약·Slack 설계를 보존한 선택 기능 사양입니다. 현재 기본 사용은 직접 링크 정리와 요청형 수집이며, 자동 예약이나 Slack 전송을 설정한 것으로 해석하지 않습니다. 현재 실행 규칙은 [수집 흐름](subagent-workflow.md)을 따릅니다.

## 실행 방식

- 과거 정기 실행 제안: 매일 오전 8시(Asia/Seoul). 실제 예약은 연결하지 않았으며 별도 요청 시 설정
- 목표: MD 최대 2건, HR 최대 2건
- 자료 목적 비율은 고정하지 않고 그날 가장 유의미한 자료를 선택
- 기준을 통과한 자료가 부족하면 개수를 채우지 않음
- 요청형 실행: 사용자가 원하는 때 추가 수집 가능
- Slack 전송: 사용자 요청 또는 예약 작업에 전송이 명시된 경우에만 수행. 정기 실행이라는 이유만으로 전송하지 않음
- 직접 링크: 품질 선별·통합 검수를 생략하고 본문을 읽어 요약·저장. 이 문서의 탐색 선별 기준을 적용하지 않음

## 처리 순서

1. 기존 저장 자료 인덱스에서 원문 링크 중복과 직무·업무 영역별 축적 현황 확인
2. 공개 자료 후보 탐색
3. 원문 본문과 출처·발행일 확인
4. 직무 직접성, 구체적인 업무, 질적인 학습 가치로 선별
5. 중복이 아니며 기준을 통과한 자료만 Notion에 저장
6. 생성된 Notion 페이지만 직접 읽어 저장 결과 확인
7. 저장 성공 자료를 영구 로컬 인덱스에 추가
8. Slack 전송이 명시적으로 요청된 경우에만 브리핑 전송
9. 실행 요약과 간단한 판단 기록 저장

## 저장 위치와 보존 기간

| 데이터 | 저장 위치 | 보존 |
|---|---|---|
| 선별 통과한 탐색 자료 또는 직접 링크의 요약 | Notion | 영구 |
| 저장된 원문 링크와 분류 | `data/archive-index.jsonl` | 영구 |
| 제외 URL·이유·확인 시각 | `data/decision-log.jsonl` | 90일 |
| 실행 건수·성공·오류 | `data/run-history.jsonl` | 90일 |
| 원문 본문 | 저장하지 않음 | 해당 없음 |
| 빠른 브리핑 | Slack `#news-briefing` | Slack 보존 설정을 따름 |

90일이 지나 다시 발견된 제외 자료는 새 정보가 추가됐는지 재평가할 수 있습니다. Notion에 이미 저장된 동일 원문 링크는 기간과 무관하게 계속 중복으로 제외합니다.

## Slack 메시지 형식

```text
📬 오늘의 취준 브리핑 · YYYY-MM-DD

🔥 오늘의 PICK

① 제목
무슨 내용? 핵심 2~3줄
💡 왜 알아야 해? 산업/MD/HR 관점 1~2줄
🔗 원문 링크

📈 오늘 보이는 흐름
서로 다른 자료 2건 이상에서 같은 변화가 직접 확인될 때만 작성

🧠 오늘 하나만 기억한다면
오늘 얻어갈 산업·직무 지식 한 문장
```

- PICK은 Notion 저장 자료 중 가치가 가장 높은 1~3건만 포함합니다.
- `오늘 보이는 흐름`은 근거 자료가 2건 미만이면 섹션 전체를 생략합니다.
- 자료가 0건이면 실제 이유만 짧게 전송합니다. 직접 링크의 중복·접근 실패를 품질 미달로 표현하지 않습니다.
- 채용·기업 소식, 면접 예상 질문, 자기소개서 문구, 질문 목록과 오늘의 용어는 넣지 않습니다.

## 실행 결과 표시

```text
🔎 후보 24개 발견
→ 본문 10개 확인
→ 4개 선정
→ 중복 2개 제외 / 기준 미달 4개 제외
→ Notion 4개 저장 완료
→ Slack 전송 완료
```

각 후보의 판단 기록에는 결과, 관련 직무·업무 영역, 적용 기준과 한 줄 근거만 남깁니다. 인공지능의 숨은 사고 과정은 저장하지 않습니다.

## 확인 기준

- 같은 링크는 다시 Notion에 저장되지 않습니다.
- 요청형 수집은 다른 URL이어도 같은 사건이면 대표 자료만 남깁니다. 직접 링크는 사용자가 고른 서로 다른 원문을 같은 주제라는 이유로 제외하지 않습니다.
- 자료 수보다 학습 가치를 우선합니다.
- Notion과 Slack의 내용이 원문에 없는 사실을 포함하지 않습니다.
- Slack은 Notion 내용을 그대로 복사하지 않고 빠른 발견과 기억에 필요한 내용만 보여줍니다.
