# Notion DB 구조

데이터베이스 이름: `산업·직무 인사이트 DB`

| 속성 | 형식 | 값 또는 설명 |
|---|---|---|
| 자료명 | 제목 | 원문 제목 |
| 자료 목적 | 선택 | 직무 공부, 산업·기업 동향 |
| 원문 링크 | URL | 정리된 원문 주소이자 중복 판정 기준 |
| 발행일 | 날짜 | 원문에서 확인한 날짜 |
| 출처 | 텍스트 | 기관·기업·언론사 이름 |
| 자료 유형 | 선택 | 뉴스, 기업 공식 홈페이지, 기술 블로그, 공식 YouTube, 보고서·공공자료, 기타 |
| 관련 산업 | 다중 선택 | 유통/커머스/리테일 |
| 관련 직무 | 다중 선택 | MD, HR |
| 업무 영역 | 다중 선택 | 아래 업무 영역 목록 사용 |
| 핵심 요약 | 텍스트 | 반드시 기억할 핵심 1~3문장 |
| 확인 상태 | 선택 | 검토 필요, 확인 완료 |
| 수집일 | 생성 시각 | Notion 자동 기록 |

## 업무 영역

MD:

- 고객·시장 분석
- 상품·브랜드 구성
- 판매 전략
- 성과·운영 관리

HR:

- 인력 계획
- 채용·온보딩
- 평가·보상
- 교육·성장
- 조직문화·노무
- HR 데이터

## 저장 원칙

- 관련성이 낮은 산업·직무 값은 비워둡니다.
- 새 자료는 `검토 필요`로 저장합니다.
- 페이지 생성 후 해당 페이지만 다시 읽어 제목, 링크, 분류와 본문을 확인합니다.
- 확인에 성공한 자료만 로컬 인덱스에 기록합니다.

## 페이지 본문 표시

- 제목은 `##` 단계로 구분합니다.
- 직무 핵심 행동과 판단 기준은 글머리표당 최대 1개, 페이지 전체 최대 6개까지 굵게 표시합니다.
- `핵심 내용`, `산업·직무 연결`, `나에게 왜 중요한가`에서 각각 최대 한 곳, 페이지 전체 최대 세 곳만 노란색 배경으로 표시합니다.
- 중요도가 낮은 섹션은 하이라이트 개수를 채우기 위해 표시하지 않습니다.
- 굵게와 하이라이트는 같은 표현에 겹쳐 쓰지 않습니다.
- 출처 정보와 URL에는 강조 표시를 사용하지 않습니다.
